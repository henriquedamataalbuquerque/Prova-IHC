# Minha Padaria — Descrição das alterações (por Aluno)

Este repositório contém um site simples chamado *Minha Padaria*. Abaixo explico, em minhas palavras, como as alterações feitas atendem aos requisitos do trabalho.

## Arquivos alterados
- `Site/Site/Minha Padaria.html` — estrutura HTML simplificada e organizada.
- `Site/Site/styles.css` — estilos mínimos aplicados para melhorar legibilidade e organização.

## 1) Affordance (navegação)
- Coloquei botões e links com destaque suficiente (fundo/hover) para que o usuário perceba facilmente o que é clicável.
- Adicionei um botão `Início` no topo para facilitar retorno à seção principal.
- Os cards de produtos têm um leve efeito de hover que indica interatividade.

Como resultado, o usuário entende por pistas visuais o que pode ser clicado, cumprindo a proposta de affordance.

## 2) Heurísticas de Nielsen aplicadas
- **Visibilidade do status do sistema:** O menu e os títulos das seções são claros; o usuário consegue identificar onde está no site.
- **Consistência e padrões:** Usei uma paleta de cores e tipografia consistente entre títulos, botões e preços.
- **Prevenção de erros:** Os links do menu usam âncoras para ir diretamente às seções (evita navegar para lugares errados).
- **Correspondência entre sistema e mundo real:** Os nomes das seções (Doces, Salgados, Encomendas) e os valores (R$) usam linguagem familiar.

## 3) Análise semiótica (signo visual)
- Escolhi um signo visual simples (ícone/emoji de pão no título) e cores quentes (marrom) que remetem a pão/forno.
- Esses elementos trabalham juntos para comunicar rapidamente que o site é de uma padaria.
